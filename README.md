# LoginMaterialYou - 2DA Evaluacion de Interfaces Moviles

Prototipo nativo de pantalla de inicio de sesion (Login) desarrollado en Android Studio con Java y XML, aplicando los estandares de diseno Material Design 3 y Material You.

## Datos Academicos
- Autor: Aguilar Martinez Juan Israel
- Carrera: Ingenieria en Sistemas Computacionales (7mo Semestre)
- Asignatura: Interfaces Moviles
- profesor: Romero Gonzales Gustavo Moises

## Caracteristicas Implementadas
- Material 3 y Material You: Integracion de colores dinamicos que adaptan la interfaz automaticamente al tema del sistema del telefono.
- Componentes Material nativos: Campos de entrada con contorno para correo y contrasena, iconografia vectorial y botones modernos.
- Validacion de formulario: Verificacion de campos de correo electronico y contrasena con retroalimentacion visual.
- Compatibilidad visual completa: Ajuste automatico de margenes de pantalla en dispositivos modernos.
- Pruebas fisicas: Compilado y validado directamente en dispositivo fisico HONOR NIC-LX3.
